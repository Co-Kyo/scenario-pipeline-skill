# 门禁与降级清单

## 分发（进并行前）

- 主 agent 只下发路径，不读子任务文件内容。
- 每个维度的角色定义、输出路径、格式章节由使用方声明。

## 门禁（进收敛前）

- 每份维度报告存在、可解析、带归属字段、条目非空。
- 判定：全部齐备 → 进入收敛；存在缺项 → 停住，输出缺失分析，等用户决策（重试或降级）。
- 重试有上限：达到上限后仅保留降级选项。

## 降级（收敛失败时）

- 触发：收敛者超时、重试仍失败、输出解析失败。
- 动作：读存活维度报告＋共享骨架，按字段映射表重建最小汇总产物（映射表由使用方声明），标注降级痕迹。
- 校验：重建产物含核心字段（非空）才算成功。
