# 并行分析

> 适用：同一主题需要多个相互独立的维度分别分析，最后汇总为一份结论时。

## 做法

1. **定维度**：选取 3–5 个互补视角，维度之间信息尽量不重叠。维度清单由使用方声明（本方法不预设维度名）。
2. **并行分析**：每个维度一个分析者，各自独立完成并写出一份维度报告到约定位置；过程中轮询等待完成，失败的分析者按约定次数补发。
3. **质量门禁**：全部维度报告齐备（或用户显式授权降级）才进入下一步；缺项时停住等用户决策，不自行补齐。
4. **收敛汇总**：由收敛者读取全部维度报告，依次执行——
   - **校验**：跨维度一致性（同一事实在不同维度给出口径不同即为不一致）；
   - **对齐**：不一致时按使用方声明的优先级取舍；
   - **收束**：把各维度的结论编织成一张关系图，明确跨维度引用关系；
   - **去重**：同维度内描述重叠则合并；跨维度同源则标注为不同视角；
   - **补位**：检测覆盖缺口，缺什么补什么或明确记为空白。
5. **产出**：按使用方声明的格式写出汇总产物（格式归使用方；本方法只要求可追溯——每条结论能指回它来自哪个维度）。

## 边界

- 本方法不含维度名、文件名、字段名与优先级具体值——这些属于使用方的业务内容。
- 门禁判定与收敛动作是可复用的通用部分；维度如何切分属于业务判断，由使用方给出。
