# briefing 产出格式

## 路径

`{workDir}/.meta/briefings/{seq}-{short_name}.md`

## Markdown 模板

```markdown
# 长列表渲染 — 组装 Briefing

## 命题信息
命题：长列表渲染：如何在万级数据量下保持流畅滚动
限定词：（无）

## 涉及能力摘要
### A1-浏览器渲染管线 [用于: overview/edge-cases/trade-offs/experiment]
机制：...
瓶颈：
  - [名称]：[触发条件] → [表现症状]
权衡：
  - [维度]：[方案A] vs [方案B]，建议 [选择建议]
实验代码：（如有）
参考：（URL 列表）

## 内容比例约束
开篇 10-15%：从限定词痛点切入
主体 ≤70%：通用工程原理
场景化/特化 ≥30%：限定词、上下文、边界、验证点

## 场景化 Trace
场景输入：
  1. [具体场景输入]
  2. [具体场景输入]
  3. [具体场景输入]
边界：
  1. [边界条件]
  2. [边界条件]
  3. [边界条件]
验证：
  1. [验证方法]
  2. [验证方法]
  3. [验证方法]
```

## 字段说明

| 字段 | 含义 |
|------|------|
| `机制` | 能力的核心技术原理（mechanism_summary） |
| `瓶颈` | 与该命题相关的工程瓶颈 |
| `权衡` | 该能力涉及的典型权衡 |
| `参考` | 按 Tier 排序的参考资料 |
| `场景化 Trace` | 每个命题至少 3 个场景输入、3 个边界、3 个验证点 |

`场景化 Trace` 是 Briefing 的机器可读结构，必须保留到后续组装阶段。
