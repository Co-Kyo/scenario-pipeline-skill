# learning-ladder 产出格式

## 路径

`{workDir}/{seq}-{short_name}/learning-ladder.md`

## 判据校准表

学习者的 target_level 来自 `{workDir}/.meta/brainstorm/anchors.json`，为每条「做到才算过」选取与水平相称的验证动作：

- **L1**：概念级：能复述定义、指认关键部件，判据以「能指出/能说清」为主
- **L2**：方案级：能在指导下完成，判据以「能照做并对照检查表验证」为主
- **L3**：决策级：能独立选型并说明取舍，判据以「能对比方案并给出理由」为主
- **L4**：体系级：能设计体系并教他人，判据以「能从零设计并讲解」为主

## Markdown 模板

```markdown
# 长列表渲染 — 学习阶梯

## 阶段一：理解渲染瓶颈（基础）
### Step 1.1：认识渲染管线
- **要做什么**：打开 Chrome DevTools → Performance → 录制一段长列表滚动
- **预计时长(分钟)**：15
- **你会看到**：火焰图中大量的 Layout 和 Paint 块
- **这说明了**：每滚动一次，浏览器都要重新布局和绘制所有 DOM 节点
- **接下来去哪**：[A1-浏览器渲染管线](../capabilities/A1-浏览器渲染管线.md) §最小验证实验
- **做到才算过**：能准确指出火焰图中 Layout 块对应的代码行
- **完成标记**：☐

### Step 1.2：...
...

## 阶段二：实现虚拟滚动（技能）
### Step 2.1：...
...

## 阶段三：性能调优与工程化（综合）
### Step 3.1：...
...

## 失败回退
- 阶段一卡住 → 回到 A1 §最小验证实验，改做更小的步
- 阶段二卡住 → 先完成 experiment/ 中的最小实验
```

## 进度留痕

每步执行后追加 `{workDir}/.meta/learning/progress.json`：

```json
{
  "entries": [
    { "step_id": "1.1", "passed": true, "stuck": null, "date": "ISO时间" }
  ]
}
```

## 字段说明

| 字段 | 含义 |
|------|------|
| `要做什么` | 具体动作（降低认知门槛） |
| `预计时长(分钟)` | 该步的时间盒，供学习者规划会话 |
| `你会看到什么` | 预期结果 |
| `这说明了什么` | 观察→知识连接 |
| `接下来去哪` | 指向可动手资源的精确路径；未通过时给更小的步 |
| `做到才算过` | 二值验证标准，按判据校准表选取 |
| `完成标记` | ☐ 未过 / ✅ 已过，与 progress.json 同步 |
